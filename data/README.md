This folder contains raw and processed datasets. 
# Data Sources

## 1. CNC Milling Machine — AI4I 2020 Predictive Maintenance Dataset
- Source: https://www.kaggle.com/datasets/stephanmatzka/predictive-maintenance-dataset-ai4i-2020
- Publisher: UCI Machine Learning Repository
- Rows: 10,000
- Columns: 14
- Failure Types: Tool Wear (TWF), Heat Dissipation (HDF), Power (PWF), 
  Overstrain (OSF), Random (RNF)
- License: CC BY 4.0


## 2. Wind Turbine — SCADA Dataset
- Source: https://www.kaggle.com/datasets/berkerisen/wind-turbine-scada-dataset
- Publisher: Kaggle / Berk Erisen
- Rows: 50,530
- Columns: 5
- Failure Label: Engineered from power deviation
- License: CC0
- 
## 3. Aircraft Engine — NASA CMAPSS FD001
- Source: https://www.kaggle.com/datasets/behrad3d/nasa-cmaps
- Publisher: NASA Prognostics Center of Excellence
- Rows: 20,631
- Columns after cleaning: 22
- Sensors retained: 17 sensor columns after dropping 4 zero-variance columns
- Target variable: RUL (Remaining Useful Life) — engineered from max cycle per engine
- License: Public Domain
